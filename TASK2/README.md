# Task 2: Graph ADT & Dijkstra’s Shortest Path Algorithm

This folder contains the self-study research and implementation for **Group 70**. We have researched and implemented a Graph Data Structure (Adjacency List) and Dijkstra's Algorithm for finding the shortest path between nodes.

## 📂 Files in this Folder
*   `graph.py`: Implementation of the Graph Abstract Data Type (ADT) using an Adjacency List.
*   `dijkstra.py`: Implementation of Dijkstra’s Algorithm using a Min-Priority Queue (via Python's `heapq`).
*   `main.py`: A demonstration script that builds a sample graph and runs the algorithm.
